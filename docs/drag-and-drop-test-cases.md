## H. 已知限制（无需报 bug）

1. 网页版/浏览器拖入文本与图片：HTML5 事件被 WRY 拦截，桌面端不触发（探针实测确认）；代码保留待 WRY 扩展。
2. 多文件拖出幽灵图为第一项图标，无 Finder 式堆叠预览。
3. 文件展示区永久禁划词（与 Finder 一致），文件名复制走「选中文件 + Cmd+C」。
4. merge 传输不进撤销历史；撤销窗口 = toast 可见期（8 秒）。
5. 进度静默阈值只按条数（≤10 项），未按总体积判断。
