## 版式与更新

最终图片只增加深蓝灰实体背景、少量外围留白和自然投影。文字、选区、文件名、状态与控件均来自截图本身。

1. 在真实应用中准备公开示例，走完对应操作，再拍摄实际状态。
2. 从原图中裁出一个连续矩形，确保账户、密钥和私人内容不在区域内；保存到 `source/`。
3. 更新 [截图配置](../../scripts/readme-screenshots/screenshots.json)，填写文件名、图片标识与说明。公开来源图已裁切时使用 `crop: null`；需要进一步聚焦时可填写实际矩形坐标。
4. 启动预览：

```bash
node scripts/readme-screenshots/server.mjs --port 5188
```

打开 `http://127.0.0.1:5188/` 查看全部图片。最终画面位于 `/capture/图片标识/slate`，默认宽度 1600。通过浏览器导出整个画面，再按 `.composition`（图片与外围背景容器）的实际边界裁出图片；内容高度小于浏览器窗口时，避免保留浏览器多余空白。

保存为对应 `.jpg` 文件后，检查首页实际宽度下的阅读效果、全部图片是否加载、章节跳转是否正确。更新截图时也要更新图注和本轮检查范围。

[页面模板](../../scripts/readme-screenshots/index.html)和[预览服务](../../scripts/readme-screenshots/server.mjs)保留在仓库，不依赖当前机器的私人临时路径。
