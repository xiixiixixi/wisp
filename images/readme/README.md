# 首页配图维护

首页的六张图片来自 Wisp 0.99.39 的实际运行界面，使用本机演示资料。图中文字、文件比较、编辑器与终端输出均为真实界面；文档画布中的问题只输入到编辑框，没有发送，也没有展示模型回答。

`images/readme/source/` 保存裁掉顶部系统状态区域后的截图来源。成图仅做裁切、缩放和版面拼排，没有重绘界面、增加不存在的控件或修改截图中的文件内容。顶部标题和底部说明属于配图说明文字，不属于应用界面。

| 成图 | 展示内容 |
| --- | --- |
| `workspace-overview.jpg` | 三个独立窗格、文档预览和底部终端 |
| `pane-layout.jpg` | 左右和上下拆分组合，资料、制作、交付目录同时保留 |
| `preview-edit.jpg` | 同一份文档的阅读与源文编辑状态，局部并排展示 |
| `file-comparison.jpg` | 两份文本的实际行级差异，比较边栏局部 |
| `canvas.jpg` | 文档列，以及对话列欢迎区、输入区的局部拼排；问题尚未发送 |
| `terminal.jpg` | 底部工具标签和真实终端输出，局部截取 |

重新生成时，需要 Python（脚本语言）与 Pillow（图片排版库），以及可显示中文的字体。脚本优先查找 macOS（苹果桌面系统）的苹方字体，也可以显式传入字体路径：

```bash
python3 scripts/render-readme-images.py
# 使用其他中文字体时
python3 scripts/render-readme-images.py --font /path/to/chinese-font.ttf
```

更新截图时先以对应的真实应用状态重新拍摄，再替换来源图，并同步调整脚本中的裁切坐标。源图宽度为 2800 像素，原始界面高度为 1640 像素；存入仓库前裁掉顶部 144 像素和底部 55 像素。脚本中的区域坐标以原始截图为基准。

生成后要按首页实际显示宽度检查标题、界面文字和差异标记，同时确认图片说明没有将配置能力或待发送问题描述成已完成的结果。
