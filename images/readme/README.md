主图来源为 `source/browser-light.png` 与 `source/browser-dark.png`：同一目录的浅色和深色原生完整窗口截图，两张均为 3670 × 2100，没有裁切或修补，保留顶部三个窗口按钮、顶栏、左侧导航、单一文件目录、左下回收站和底部状态栏。主图将两张完整截图等宽并排。

## 版式与更新

主图使用浅蓝灰实体背景，将两个主题等宽并排；其他功能图保留深蓝灰实体背景。最终图片只增加少量外围留白和自然投影。文字、选区、文件名、状态与控件均来自截图本身。

1. 在真实应用中准备公开示例，走完对应操作，再拍摄实际状态。
2. 使用原生系统窗口截图，采集前关闭鼠标捕获；先通过真实界面收起或最小化被控制的窗口，等待窗口动画完全结束，再采集该窗口的独立完整内容。此方式保留真实窗口内容，同时避免鼠标、光圈与紫色共享控制标识进入原图。不要在窗口缩放或最小化动画尚未结束时拍摄，避免画面倾斜或变形。
3. 主图保存完整应用窗口原图，不作裁切或修补；功能图才从原图裁出连续矩形。保存到 `source/` 前检查所选区域，确保账户、密钥、私人档案和记忆内容均不在其中。
4. 对每张公开来源逐张人工放大查看整幅画面，重点检查顶部、左下角和操作过的控件，确认没有虚拟鼠标、光圈、紫色共享标识或窗口动画产生的倾斜变形。不能只校验尺寸或文件能否读取。
5. 更新 [截图配置](../../scripts/readme-screenshots/screenshots.json)，填写文件名、图片标识与说明。公开来源图已裁切时使用 `crop: null`；需要进一步聚焦时可填写实际矩形坐标。
6. 启动预览：

```bash
node scripts/readme-screenshots/server.mjs --port 5188
```

打开 `http://127.0.0.1:5188/` 查看全部图片。最终画面位于 `/capture/图片标识/slate`，主图默认宽度 2400，其他图片为 1600。通过浏览器导出整个画面，再按 `.composition`（图片与外围背景容器）的实际边界裁出图片；内容高度小于浏览器窗口时，避免保留浏览器多余空白。

保存为对应 `.jpg` 文件后，再对每张成图逐张人工放大检查鼠标、光圈、紫色共享标识和倾斜变形；来源检查通过不代替成图检查。最后检查首页实际宽度下的阅读效果、全部图片是否加载、章节跳转是否正确，不能将加载成功当作画面检查通过。更新截图时也要更新图注和本轮检查范围。

[页面模板](../../scripts/readme-screenshots/index.html)和[预览服务](../../scripts/readme-screenshots/server.mjs)保留在仓库，不依赖当前机器的私人临时路径。
