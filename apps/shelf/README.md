# Wisp 内置收集架

收集架现在属于 Wisp（文件管理器），不再提供单独启动的应用。

- 左侧导航的“收集架”管理全部架子，支持缩略图与列表。
- Wisp 设置中的“收集架”集中配置激活、交互、操作、分享和文件夹观察。
- 悬浮架仍是原生小窗，可以在主窗口关闭后继续收集与拖出文件。
- Wisp 菜单栏提供新建、从剪贴板创建、固定架子、最近关闭、管理和设置。

普通文件仍保存原位置引用，不会因为加入或移除条目而搬动、删除原件。
文字、链接、图片及附件的实际副本，和以前的记录继续保存在
`~/Library/Application Support/WispShelf`（用户资料库中的收集架目录）。
为了兼容已有数据与授权，内部组件及资料目录沿用原名称；这不代表它还是独立产品。

## 开发

从主项目准备内置组件，然后使用 Wisp 的正常开发流程：

```sh
pnpm -w shelf:prepare --dev
pnpm -w tauri:dev
```

`shelf:prepare`（准备内置组件）生成苹果芯片和英特尔两种架构，产物放在
`apps/src-tauri/shelf-engine`（内部组件目录）。`build.sh`（组件打包脚本）只接受
主项目提供的内置组件参数，不再生成 `dist/WispShelf.app`（独立应用）。

本机调试包不等于已签名、公证的正式发行版。云上传、系统快捷指令、跨应用拖放、
多屏和旧系统的兼容性，应分别按实际验证结果判断，不能用编译通过代替。
历史功能范围见 [REFERENCE-AUDIT.md（竞品对照）](REFERENCE-AUDIT.md)。
