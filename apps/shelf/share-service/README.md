# 本机分享服务

这是 WispShelf（独立收集架）可连接的一个小型自建服务。它先接收文件，再返回下载地址；不是 Dropover Cloud（参考产品的私有云），没有账号登录、分享页装修或历史文件管理界面。

**当前已验证本机上传、下载内容一致、撤销和到期拒绝。没有公开部署，也没有验证互联网、反向代理或正式云账号。** 服务只监听 `127.0.0.1`（本机回环地址），其他电脑不能直接打开本机生成的链接。

## 能力与验收

| 操作 | 当前规则 | 已验收及限制 |
|---|---|---|
| 上传文件 | 每次一个文件，必须提供上传密钥；默认最多 250 MiB（262144000 字节） | 实际上传和无凭据的 401（未授权）拒绝已验证；文件夹请先压缩 |
| 下载链接 | 取得地址的人可以下载，不要求登录；返回原文件字节 | 内容逐字节一致已验证。这是凭链接访问，不是指定收件人访问 |
| 撤销链接 | 使用同一上传密钥请求删除；删除服务中该链接的文件和记录 | 未授权撤销被拒绝，合法撤销后下载返回 404（找不到）已验证；不影响上传前的原文件 |
| 链接到期 | 默认七天；到期下载返回 410（已过期） | 到期拒绝已验证，但过期文件不会自动从磁盘清理 |
| 安全范围 | 上传和撤销需要密钥，下载链接包含随机编号；文件保存在指定目录 | 不等于完整公网服务：没有访问次数限制、病毒检查、备份或用户管理，服务端目录需自己保护 |

默认大小和期限来自服务代码，不是收集架设置页上的可调项。收集架目前没有一键撤销按钮或云历史管理；服务接口提供撤销，并不表示界面已提供完整管理流程。

## 在本机启动

需要 Node.js（服务运行环境）。以下命令只在主动执行后启动；密钥随机生成，不使用固定示例密钥。命令会把新密钥放进剪贴板，替换当前复制内容，便于在应用中填写：

```sh
# 从仓库根目录进入服务目录
cd apps/shelf/share-service
export SHELF_SHARE_TOKEN="$(/usr/bin/openssl rand -hex 32)"
export SHELF_SHARE_DIR="$HOME/Library/Application Support/WispShelfShare"
printf '%s' "$SHELF_SHARE_TOKEN" | pbcopy
PORT=5198 node server.mjs
```

终端会显示本机上传地址，通常为 `http://127.0.0.1:5198/upload`（本机上传入口）。端口被占用时可换另一个端口；`PORT=0`（自动分配空闲端口）会在启动输出中报告实际地址。停止服务后链接暂时无法访问，未撤销且未过期的文件仍留在保存目录。

在收集架“云分享”中添加“自定义云服务”：名称自定，接口地址填启动输出中的上传地址，密钥粘贴刚生成的值，公开链接地址在此服务连接方式中不用填写。保存配置不表示已经连接；实际上传仍要再次确认。配置完成后不要把这段密钥当作普通下载链接分享；剪贴板历史工具也可能保留它。

密钥至少 16 个字符。不要把密钥写入版本库、日志或分享给下载者；知道上传密钥的人也拥有撤销权限。服务没有恢复遗失密钥的账号系统，重新生成密钥会改变后续上传和撤销所需凭据。

| 配置名称 | 中文含义 | 当前行为 |
|---|---|---|
| `SHELF_SHARE_TOKEN` | 上传和撤销密钥 | 必填，至少 16 个字符 |
| `SHELF_SHARE_DIR` | 服务文件保存目录 | 未填时使用服务工作目录内的 `.local-share-data`（本机分享数据目录）；建议主动指定私有目录 |
| `PORT` | 监听端口 | 默认 5198；填 0 时自动分配 |
| `SHELF_SHARE_PUBLIC_URL` | 返回链接使用的外部基址 | 仅改变返回地址，不会自动开放端口、启用加密或部署到公网 |

## 与收集架的约定

收集架逐文件发送原始内容，而不是把整批伪装成一个已打包文件。普通文件上传不会改动本机原件。

| 请求 | 需要的内容 | 成功响应 |
|---|---|---|
| `POST /upload`（上传） | 文件原始字节；`Authorization: Bearer <密钥>`（访问凭据）；`Content-Type: application/octet-stream`（二进制文件）；`X-Filename`（经过百分号编码的原始文件名） | 201（创建成功），返回 `url`（下载地址）和 `expiresAt`（到期时间） |
| `GET /f/<编号>`（下载） | 下载地址，无需上传密钥 | 200（成功）及文件字节 |
| `DELETE /f/<编号>`（撤销） | 同一上传密钥 | 200（成功），返回 `revoked: true`（已撤销） |

响应是 JSON（结构化数据）。失败状态不会被收集架当成分享成功；批次后项失败时，前面已成功的链接仍保留，不自动重传或删除。不要因为只看到一个网址就判断它已能从外网访问。

## 本机测试与公网边界

本地保留的 `server.test.mjs`（服务测试）检查真实字节、授权、撤销和短期限到期。收集架的 `Tests/ShelfCoreTests/LoopbackUploaderTests.swift`（本机真实上传测试）使用临时端口、临时保存目录和测试密钥，运行结束终止服务并清理；找不到运行环境会明确跳过。测试文件不随源码仓库分发，以下命令仅适用于保留了本地测试的工作区。

```sh
node --test server.test.mjs
```

上面的命令运行服务测试，不是公开部署。远程接入必须使用 HTTPS（加密网址）；收集架仅对本机回环地址允许 HTTP（非加密网址），并禁止自动重定向，以免把凭据交给不同服务器。

对外提供之前，还需自行部署加密入口、核对外部下载和撤销、限制滥用，并安排到期文件清理。只填写外部基址不能完成这些步骤。当前没有互联网可用、长期稳定或完整安全审核的承诺；不要用未验收的公开配置上传私密文件。
